#T08.01c.- Redox: Identificación de reacciones redox

🔧 Identificación de reacciones redox

📌 Teoría mínima necesaria

Una reacción es REDOX ⟺ algún número de oxidación CAMBIA entre reactivos y productos.

Recuerda las dos definiciones clave:

  • OXIDACIÓN: el n.o. aumenta → el elemento PIERDE electrones.
  • REDUCCIÓN: el n.o. disminuye → el elemento GANA electrones.

Y las dos identidades (¡ojo, son "cruzadas"!):

  • El que pierde e⁻ es el REDUCTOR (se oxida).
  • El que gana e⁻ es el OXIDANTE (se reduce).
\[ \text{Nº e}^-\text{ transferidos} = |\text{n.o. final} - \text{n.o. inicial}| \]

Método en 4 pasos: (1) calcula n.o. de cada elemento en reactivos y productos; (2) compara si sube o baja; (3) identifica oxidante/reductor; (4) comprueba que los e⁻ perdidos = e⁻ ganados.

Clave para el examen: una reacción es redox si y solo si algún número de oxidación cambia entre reactivos y productos. Si todos los n.o. se mantienen idénticos, NO es redox (aunque haya iones, precipitados o agua). Y recuerda: el oxidante se reduce y el reductor se oxida. ¡Grábatelo bien!
